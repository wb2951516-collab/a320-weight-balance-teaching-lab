# 算法核实记录 · 配载平衡教学

## 核心公式（已手工复核）

| 量 | 公式 | 说明 |
|----|------|------|
| 力矩 | `M = W × Arm` | Arm = 自机头 DATUM(FS0) 向后的站位 m |
| 纵向重心 | `CGx = Σ(W×Arm) / ΣW` | |
| %MAC | `%MAC = (CGx − LEMAC) / MAC × 100` | LEMAC=16.92 m，MAC=4.1935 m |
| 横向重心 | `CGy = Σ(W×y) / ΣW` | y 左负右正 |
| 教学包线 | **18% ~ 36% MAC** | 示意值，实机以 AFM/WBM 为准 |

**空机校验：** OEW=42500 kg @ OEW_ST=17.968 m → **%MAC = 25.00**（与 `OEW_MAC_PCT=25` 一致）。

## 为何旧版“极端参数也不出包线”

1. **HTML 旧站位过于靠近 OEW 重心**（前舱 13.15 / 后舱 16.10，且 LEMAC=13.0），前重工况仅约 **21%**，仍落在 20–34% 内。  
2. **Blender 预设不够极端**（前重仍带中舱+中等货油），在 A320 站位下也可能仍在包线内。  
3. 公式本身无误——用 `a320_data.py` 复核后，真正极值可出限。

## 讲解时注意

- 色条高度表示**重量占比**；计算用的是**站位 Arm**，两者不必像素级一致。  
- OEW 占起飞重量一半以上，空机本身就在 25% 附近；**只有足够大且偏前/偏后的业载才能把 CG 拉出包线**——这正是教学要点。  
- 实机包线随重量/构型变化，本模型为固定示意包线。
