# 机型与参考资源（民航配载教学）

## 推荐教学机型：空客 A320 系列（含 A320neo）

**为什么选 A320 做新员工配载教学：**

1. **国内机队占比高**，新工入职场景最贴近实际
2. **前/后货舱 + 散装舱** 结构清晰，能讲清舱位对 CG 的拉动
3. **公开资料最全**：ACAP、WBM 逻辑、培训教材丰富
4. **窄体单通道**：旅客分舱（前/中/后）与 %MAC 关系直观，课堂不过载
5. 与 B737 同属窄体，概念可平移

> 本教学模型按 **A320-200 ACAP 量级**（非正式性能数据）：L=37.57 m，B=34.10 m，MAC=4.1935 m，OEW≈42.5 t，MTOW 教学值 78 t，包线示意 **18%~36% MAC**。真实包线以该注册号 AFM/WBM 为准。

## 三轴平衡教学要点（对应本模型）

### 1. 静平衡（铅垂方向）
- 平飞：升力 L ≈ 重量 W，ΣFz = 0
- W = OEW + 旅客 + 行李 + 货邮 + 燃油
- 超 MTOW：减载或减油
- 配载单上的 **TOW / ZFW** 先解决「有多重」

### 2. 俯仰平衡（纵向，教学核心）
- **力矩** M = W × Arm（Arm 从 DATUM 向后量）
- **CGx** = Σ(W·Arm) / ΣW
- **%MAC** = (CGx − LEMAC) / MAC × 100
- 前重 → 低头力矩大 → 带杆/升降舵上偏、配平阻力大
- 后重 → 抬头趋势 → 安定裕度变差，可能失去恢复能力
- 教学检查：CG 落在 **前限与后限之间**（本模型示意 20%~34%）

### 3. 横滚平衡（横向）
- **CGy** = Σ(W · yi) / ΣW（yi：相对机身中线，左负右正）
- 左右翼油差、左右货舱/集装箱不对称是主因
- 偏左 → 右倾趋势 → 右压杆/副翼配平
- 教学检查：|CGy| 与油差在限制内（本模型示意 |y|≤0.35 m，油差≤800 kg）

### 4. 姿态关联（讲给新工的一句话）
> 静平衡告诉你「能不能起飞（重量）」；俯仰平衡告诉你「抬头还是低头（%MAC）」；横滚平衡告诉你「往哪边压杆（横向 CG）」。配载单把三件事一次算完，超限就不能放行装机。

## 上下游数据如何汇入

```
值机/离港 (旅客人数、分舱座位)
行李 (件数/重量 → 前/后货舱)
货运 (货邮/ULD → 前舱、后舱、散装)
加油 (左/右翼油、中央油箱)
OEW/设备 (空机重量与空机 CG)
        ↓
   配载平衡计算 (TOW, ZFW, CG, %MAC, 横向 y)
        ↓
   装载单 / 舱单 → 机组 + 装卸 + 平衡放行
```
